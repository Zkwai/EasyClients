# Easy Clients

**Easy Clients** est une application Windows qui regroupe, au même endroit, les meilleurs **éditeurs de sauvegarde** et les **codes de triche officiels** de tes jeux solo & multijoueur . Plus besoin de chercher le bon outil sur dix sites différents : tu choisis ton jeu, l'appli te propose l'éditeur qui va avec, l'installe proprement et sauvegarde tes fichiers avant que tu modifies quoi que ce soit.

[**⬇ Télécharger la dernière version**](https://github.com/Zkwai/EasyClients/releases/latest)

---

## Ce que fait Easy Clients

### 💾 Éditeurs de sauvegarde, en un clic
Pour chaque jeu, Easy Clients propose l'éditeur de sauvegarde reconnu par la communauté :

- Le bouton **Installer** télécharge l'outil depuis **sa release officielle sur GitHub** ;
- le fichier est **vérifié par SHA-256** avant d'être installé : s'il ne correspond pas à la version officielle, il est refusé ;
- le bouton **Copie de secours** copie ton dossier de sauvegardes dans `Documents\Easy Clients Backups` avant toute modification ;
- le bouton **Ouvrir** t'emmène directement là où le jeu range ses sauvegardes.

### 🎮 Codes de triche officiels
Les codes que les studios ont prévus pour leurs joueurs, triés par catégorie, avec la façon de les activer : **GTA V, GTA IV, GTA San Andreas, GTA Vice City, GTA III, Minecraft, Counter-Strike 2, Dota 2, Borderlands**.
Ces codes fonctionnent en **mode histoire / solo / partie locale** uniquement.

## Installation

1. Télécharge **`EasyClients.exe`** depuis la [dernière release](https://github.com/Zkwai/EasyClients/releases/latest).
2. Lance-le. Aucune installation n'est nécessaire.
3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires** puis **Exécuter quand même** : l'exe n'est pas signé numériquement.

Ensuite, l'appli se met à jour toute seule.

## Conseils
- **Ferme le jeu** avant de modifier une sauvegarde.
- **Désactive la synchronisation cloud** du jeu (Steam Cloud, etc.) pendant tes modifications, sinon l'ancienne sauvegarde peut revenir.
- Garde toujours une copie : utilise le bouton **Copie de secours** avant d'éditer.
